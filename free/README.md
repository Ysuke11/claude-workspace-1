# Free（共通プロジェクト）

自宅PC・会社PC・スマホ・iPad のどこからでも同じ内容を見て、続きから作業するための共通プロジェクトです。
テーマは決めず、自由に使います。

## 使い方

1. どの端末でも Claude アプリ（または claude.ai/code）を開く
2. 「Code」でリポジトリ `claude-workspace-1` を選び、新しいセッションを始める
3. 最初に「free フォルダで作業して」と伝える

作業内容は GitHub に保存されるので、別の端末で開いても同じ状態から続けられます。

## フォルダ構成

| フォルダ | 用途 |
|---|---|
| `notes/` | メモ・アイデア・調べたことのまとめ（Markdown） |
| `files/` | 資料・データなどのファイル置き場 |
| `CLAUDE.md` | このフォルダで作業するときの Claude への共通指示 |
