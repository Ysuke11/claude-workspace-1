# 事実と仮説を分けた報告

ユーザー（佐々木さん）への報告は、**事実と仮説を必ず分離**して書く。混ぜた文章で報告しない。

## フォーマット

```
## 【事実】データから直接言えること
- 数値・観測結果のみ。計算方法が明示できるものだけをここに書く
- 出典（どのデータ・どの期間・どの定義で計算したか）を添える

## 【仮説】解釈・推測
- 事実から推測したこと。1件ごとに:
  - 根拠となる事実
  - 確度（高/中/低）
  - 検証方法（何を見れば白黒つくか）
```

## 判定基準

**事実に入れてよいもの:**
- データから計算した数値（件数・率・中央値など）
- 定義を明示した上での分類結果（例:「折返し=24h以内の同一番号への発信、と定義した場合143件」）

**仮説に入れるもの（事実に混ぜてはいけない典型例）:**
- 因果の主張（「折返しが遅いから流出した」← 相関しか見えていない）
- 「〜に依存している」「〜が原因」「〜できていない」などの解釈語
- 現場の運用状態の推測（データに現場の行動理由は写っていない）
- 選択バイアスを含む比較（例: 折返しあり群の回収率が高い ≠ 折返しの効果）
- 欠損・未突合データを補った推定値

## 注意

- 結論を先に書くのは維持する。ただし結論文の中でも「（事実）」「（仮説）」を明示する
- 仮説を書くこと自体は推奨。ただし必ず確度と検証方法をセットにする
- 定義に依存する数値は定義を併記する（定義が変われば数値も変わるため）
